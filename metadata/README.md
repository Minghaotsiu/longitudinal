# Metadata

- `scientific_data_sample_crosswalk.csv`: linkage among corrected sample IDs,
  sampling method, seed-by-Day assignment and source labels.
- `sample_metadata_34.tsv`: clean repository/submission metadata for all runs.
- `qc_metrics_corrected_long.csv`: long-form technical metrics keyed by corrected
  sample IDs.

Original sequencing-delivery labels are retained only for provenance. The
scientific grouping is `MN` versus `Bulk` and the recorded Day is Day0-Day3.
