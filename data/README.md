# Processed data

Place the processed matrices and metadata here, under:

`data/doudou_all34/`

The downstream scripts start from the following files:

- `ALL_34_raw_counts_matrix.csv`
- `ALL_34_1M_counts_matrix.csv`
- `ALL_34_sample_metadata.csv`
- `ALL_34_QC_metrics.csv`
- `soybean_gene_symbol_map.csv`

These files are archived separately because large sequencing and processed
matrices should not be committed to Git. Raw FASTQ data are available through
GSA BioProject `PRJCA078283`.
